# OIL Data Analyzer

OIL Data Analyzer is a Python desktop application for viewing and analyzing
CSV measurement data generated by the OIL measurement and logging system.

## Features

- CSV file viewer with paginated table display
- Automatic detection of measurement columns
- Line charts for time-series data
- Delta (Δ) comparison between measurement series
- Histograms with basic statistics
- Scatter plots
- Time-range filtering
- Raw, 1-minute average, and 1-hour average views
- Interactive graph tooltips
- PNG graph export up to 8K resolution
- Support for multiple CSV delimiters and text encodings

## Requirements

- Python 3
- Tkinter
- Matplotlib
